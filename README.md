# Pinterest Traffic System

## Phase 1 – Pin Factory (Impressions Validation)

Generate Pinterest-ready keyword clusters, pin copy, and a 30-day posting plan to validate search demand before building a website.

### Usage

```bash
python pin_factory.py --niche "tarot journal printables"
```

### Outputs

- `output/keywords.csv` – keyword clusters by theme
- `output/pins.csv` – pin titles, descriptions, and formats
- `output/plan.md` – 30-day posting plan
